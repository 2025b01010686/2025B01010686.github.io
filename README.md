# Amazon Clone

A frontend Amazon clone built from scratch using HTML and CSS.

## Features

- Amazon-style navigation bar
- Search bar
- Location and language section
- Product/category sections
- Responsive layout
- Footer sections

## Technologies Used

- HTML
- CSS

## Project

This project was created as a practice project to improve my HTML and CSS skills and understand how real-world websites are structured.
